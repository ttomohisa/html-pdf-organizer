使い方と注意事項

基本操作

  • PDF・JPG・PNG・WebPを追加すると、PDFの各ページと画像が同じ一覧にサムネイルで表示されます。
  • カードのどこをつかんでもドラッグでき、ページ順をすばやく変更できます。
  • 複数ページを選択してから選択中のカードをドラッグすると、まとめて順番を移動できます。
  • カードをクリックして選択し、複数ページをまとめて回転・削除できます。
  • カードの拡大ボタン、またはカードをダブルクリックするとページを大きくプレビューできます。
  • PDFと画像を好きな順に並べて、1つのPDFとして結合保存できます。画像は Fit / Fill / Original Size を選べます。
  • 画像の Fit は全体をA4内に収め、Fill はA4いっぱいに中央配置してはみ出しを切り取り、Original Size は画像自体の大きさに合わせたページを作ります。

複数選択

カード右上のチェックをクリックすると、Ctrl / ⌘ クリックと同様に現在の選択を残したまま追加・解除できます。Shift を押しながらカードをクリックすると範囲選択できます。

キーボード操作

Ctrl/⌘ Aすべてのページを選択 Ctrl/⌘ Z元に戻す Ctrl/⌘ ⇧ Zやり直す Delete選択ページを削除 Esc選択を解除

プライバシー

選択したPDF・画像の読み込み、プレビュー、編集、保存はすべてブラウザ内で行われます。ファイルや操作内容を外部へ送信せず、必要なライブラリと表示用データもこのHTML内に内包されています。

制限事項

  • パスワード付きPDFは正しいパスワードで開けます。出力PDFにも必要に応じてAES-256のパスワードを設定できます。
  • 保存時に、しおり、添付ファイル、電子署名、フォームなどの文書レベル情報が引き継がれない場合があります。
  • 電子署名付きPDFを編集すると、署名は無効になります。
  • ページ数や画像量が多いPDFでは、端末のメモリを多く使用します。
