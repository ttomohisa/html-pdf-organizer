# Changelog

## v1.0

- Added additive checkbox selection.
- Added lightweight page preview with desktop and mobile controls.
- Preserved the entered filename when exporting selected pages.
- Embedded an SVG favicon.
- Added Japanese and English UI to one HTML file.
- Replaced drag-handle sorting with whole-card Pointer Events dragging.
- Added grouped movement for multiple selected pages.
- Added stacked multi-page drag preview and count badge.
- Separated mobile scrolling from drag initiation using a short hold.
- Added accelerated continuous edge auto-scroll on mobile.
- Fixed drag preview remnants after completed or interrupted gestures.
- Removed SortableJS.
- Added a reproducible fully offline builder that embeds PDF.js, pdf-lib, workers, fonts, CMaps, WASM, ICC profiles, and related runtime assets.
- Added strict runtime network blocking and dependency hash manifests.
- Added GitHub Pages demo links, bilingual deployment documentation, and an automated Pages deployment workflow.
